# JAKS Reckoner data

Data for the JAKS Reckoner app (JAKS staff), Tax Year 2026-27. The app accepts `data.json` only with a valid signature in `data.json.sig`. Quick reference only; check the Act and Rules for a specific transaction.

## Approving a phone
Actions → **Approve phone** → Run workflow → choose approve or remove, paste the device code shown on the phone's lock screen → Run.
`devices.json` is the master list of approved codes; local publishing keeps it.
